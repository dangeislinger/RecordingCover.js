# RecordingCover

**RecordingCover** is a Wikipedia user script designed to streamline the process of uploading album or song cover art directly from an article page and automatically integrating it into the article's infobox and talk page.

* **Author:** [Widgetkid](https://en.wikipedia.org/wiki/User:Widgetkid)
* **Source Script:** [`User:Widgetkid/RecordingCover.js`](https://en.wikipedia.org/wiki/User:Widgetkid/RecordingCover.js)
* **Status:** Beta

> **⚠️ Disclaimer (Use at your own risk):** This script is currently in beta. Please report any bugs or unexpected behavior to the author on their [Wikipedia talk page](https://en.wikipedia.org/wiki/User_talk:Widgetkid).

---

## ✨ Features

* **Direct Cover Art Uploads:** Upload album or song cover art directly from the relevant Wikipedia article page.
* **Flexible Licensing:** Supports uploading non-free files under a fair use rationale to English Wikipedia, or routing public domain/free files directly to **Wikimedia Commons**.
* **Automated Infobox Integration:** Automatically adds the newly uploaded cover art to the article's album or song infobox (if present).
* **Talk Page Maintenance:**
  * Removes the `imageneeded` parameter from `{{WikiProject Albums}}` talk page banners.
  * Optionally removes `needs-infobox`, `{{Infobox requested}}`, and `{{Reqinfobox}}` tags from the associated talk page.
  * Automatically creates File talk pages tagged with the relevant WikiProjects (Albums or Songs).
