== Features ==
*Uploads cover art directly from an album or song article page. The script uploads the file under fair use rationale.
*Adds the uploaded cover art to the album or song infobox, if one exists.
*Removes 'imageneeded' flag from talk page banners, if present.

== Installation ==
*Click the "'''Install'''" button on the top of the page.
:*Alternatively, copy the line <code>importScript('User:Widgetkid/RecordingCover.js'); ''// Backlink: [[User:Widgetkid/RecordingCover.js|<nowiki>[[User:Widgetkid/RecordingCover.js]]</nowiki>]]''</code> , then paste it into your [[Special:MyPage/common.js|common.js file]].

*After installation, the link "''Upload Book Cover''" will appear in the "''Tools''" menu.

== Parameters ==
[[File:Widgetkid RecordingCover UI v1.1.1.png|thumb|right|User interface]]
#'''Article Title''' - The name of the album or song article. Should be auto-populated if you are on the article's page.
#'''Source of the file''' - The URL of the source where you found the cover art.
#'''Preset''' - Selecting a value for a record label populates several public domain fields. Optional.
#'''Author / copyright holder''' - Enter either the recording artist or the label's name.
#'''Public Domain Checkbox''' - If this file is in the public domain, check this box to send the file to Wikimedia Commons instead of to Wikipedia as a non-free file.
#'''PD Tag''' - Select the appropriate public domain tag. Required if PD checkbox checked.
#'''PD Tag Basis''' - Describe why the public domain tag you selected applies to this file. Required if PD checkbox checked.
#'''Add to Infobox Checkbox''' - Confirm you want to add the cover art to the article's Infobox.
#'''Remove 'imageneeded tag' Checkbox''' - Confirm you want to remove the [[Template:WikiProject Albums]] parameter 'imageneeded' from the album's talk page. Only works for albums. A similar parameter doesn't exist for songs.
#'''Remove needs-infobox tag Checkbox''' - Confirm you want to remove any existing needs-infobox tag from the related Talk page.
